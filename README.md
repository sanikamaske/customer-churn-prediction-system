Project Description
Customer Churn Prediction System is a Machine Learning project that predicts whether a customer is likely to leave a company based on their demographic, service usage, and account-related information. The project includes data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation. Machine Learning algorithms are used to identify customers at risk of churn and generate predictions. The system can help businesses understand customer behavior and take suitable retention actions.
Technologies: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit.

Steps

1. Data Collection – Collect customer information and churn data.


2. Data Preprocessing – Handle missing values, duplicate records, and categorical data.


3. Exploratory Data Analysis (EDA) – Analyze customer behavior and identify important patterns.


4. Feature Engineering – Select and prepare relevant features for prediction.


5. Data Splitting – Divide the dataset into training and testing sets.


6. Model Training – Train Machine Learning models such as Logistic Regression, Decision Tree, and Random Forest.


7. Model Evaluation – Evaluate the models using accuracy, precision, recall, F1-score, and confusion matrix.


8. Churn Prediction – Predict whether a customer is likely to churn or stay.


9. Deployment – Create an interactive prediction interface using Streamlit.

10. Model Used
Logistic Regression – baseline classification model
Decision Tree Classifier – identifies decision patterns in customer data
Random Forest Classifier – combines multiple decision trees to improve prediction performance

Result

Random Forest Classifier achieved 100% accuracy on the evaluated test dataset.

The system successfully predicts whether a customer will churn or stay.

Customer data is analyzed to identify churn-risk customers.

The model provides data-driven predictions for customer retention analysis.

The project demonstrates the practical use of Machine Learning for churn prediction.
